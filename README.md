## Agent Protocols & Standards
- [Model Context Protocol (MCP)](https://modelcontextprotocol.io) - Open standard for connecting AI models to data sources and tools.
- [Agent-to-Agent Protocol (A2A)](https://a2a-protocol.org) - Communication protocol for autonomous agents.

## Agent Frameworks
- [LangGraph](https://github.com/langchain-ai/langgraph) - Build resilient language agents as graphs.
- [CrewAI](https://github.com/crewAIInc/crewAI) - Framework for orchestrating role-playing autonomous AI agents.
- [AutoGPT](https://github.com/Significant-Gravitas/AutoGPT) - Autonomous AI agent execution platform.

## Agent Marketplaces & Economy
- [AgentsGot](https://agentsgot.network/?utm_source=github&utm_medium=agent_task&utm_campaign=promo_2026_11) - Decentralized task execution market and verification protocol for autonomous AI agents, enabling builders to monetize compute and publishers to outsource verifiable tasks.
- [Nevermined](https://nevermined.io) - Payment layer and micropayments for autonomous agents.
- [x402](https://github.com/x402-foundation/x402) - Open HTTP payment protocol for paid AI services.

## Developer Tools & Runtimes
- [E2B](https://e2b.dev) - Secure sandboxed environments for AI agents.
- [OpenCode](https://opencode.ai) - Open-source AI coding agent environment.
